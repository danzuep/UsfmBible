UsfmBible

A free, ad-free Bible reader for Android. Download translations from eBible.org and read them offline.

Get it on F-Droid Download APK

Features

  • Hundreds of free translations in many languages, including right-to-left scripts
  • Works offline once a translation is downloaded
  • Search, verse notes, parallel verses and reading progress
  • Day and night themes

Install with F-Droid

  1. Install F-Droid.
  2. Tap the button above (or add the repository below in Settings, Repositories).
  3. Install UsfmBible and receive updates automatically.

Repository: https://danzuep.github.io/UsfmBible/fdroid/repo
